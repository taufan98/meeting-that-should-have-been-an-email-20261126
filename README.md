## The line

> This meeting could have been an email, but the email would have needed a meeting to explain it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (95 characters, within the 1–199 gate) and nothing else.
